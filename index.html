Konfigurasi Google Apps Script

Masukkan Web App URL yang didapat dari deploy Google Apps Script Spreadsheet Anda. Portal akan mengirimkan data presensi ke URL ini setiap kali karyawan melakukan check-in.

Pastikan deployment diatur dengan izin akses: Anyone (Siapa saja).

Panduan Menghubungkan Google Sheets

1 Buat Google Sheets Baru

Buka sheets.new. Beri nama file, misalnya "Data Presensi Karyawan". Baris pertama (header) akan otomatis dibuat oleh skrip jika sheet masih kosong.

2 Buka Editor Apps Script

Pada menu Google Sheets, klik Extensions (Ekstensi) → Apps Script.

3 Salin Kode Apps Script (Code.gs)

Hapus isi skrip default di editor, lalu salin seluruh kode di bawah ini: 

// Google Apps Script (Code.gs) untuk Portal Presensi
function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.tryLock(10000);
  
  try {
    var doc = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = doc.getSheetByName("Presensi") || doc.getActiveSheet();
    
    // Auto buat header jika sheet baru
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Timestamp",
        "Nama Karyawan",
        "NIP / ID",
        "Cabang / Unit",
        "Tipe Presensi",
        "Shift",
        "Latitude",
        "Longitude",
        "Google Maps URL",
        "Catatan",
        "Foto Selfie (Data URL / Status)"
      ]);
      sheet.getRange(1, 1, 1, 11).setFontWeight("bold").setBackground("#dcfce7");
    }
    
    var rawData = e.postData.contents;
    var data = JSON.parse(rawData);
    
    sheet.appendRow([
      data.timestamp || new Date().toISOString(),
      data.nama || "-",
      data.nip || "-",
      data.cabang || "-",
      data.tipe || "-",
      data.shift || "-",
      data.latitude || "-",
      data.longitude || "-",
      data.mapsUrl || "-",
      data.catatan || "-",
      data.hasPhoto ? "Terkonfirmasi Wajah" : "Tanpa Foto"
    ]);
    
    return ContentService.createTextOutput(
      JSON.stringify({ status: "success", message: "Presensi berhasil dicatat" })
    ).setMimeType(ContentService.MimeType.JSON);
    
  } catch (error) {
    return ContentService.createTextOutput(
      JSON.stringify({ status: "error", message: error.toString() })
    ).setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock();
  }
}

function doGet(e) {
  return ContentService.createTextOutput(
    JSON.stringify({ status: "ready", message: "Apps Script Active" })
  ).setMimeType(ContentService.MimeType.JSON);
}

4 Deploy sebagai Web App

  1. Klik tombol biru Deploy → New deployment (Penerapan baru).
  2. Pilih icon gerigi (Select type) → pilih Web app.
  3. Pada Execute as: pilih Me (email Anda).
  4. Pada Who has access: pilih Anyone (Siapa saja) — Sangat penting agar portal bisa kirim data tanpa login Google!
  5. Klik Deploy, lalu berikan izin Google (Authorize Access).
  6. Salin Web app URL yang dihasilkan (berakhiran /exec), kemudian tempelkan di menu "Pengaturan Sheets" portal ini.

Agar file ini memiliki alamat web publik (seperti https://presensi-tasik.vercel.app), unggah file index.html ini ke salah satu platform gratis berikut:

Netlify Drop (Paling Mudah) Cukup seret & lepas file index.html, langsung jadi link. Vercel Cepat, stabil, domain gratis .vercel.app. GitHub Pages Gratis selamanya langsung dari repository GitHub.

3 Pasang Icon di Layar Utama HP Karyawan (Seperti Aplikasi Asli)

Karyawan tidak perlu mengetik link setiap hari. Arahkan mereka untuk menyimpan portal ke layar HP:

  • Di Android (Google Chrome): Buka link web → klik titik tiga di kanan atas → pilih "Tambahkan ke Layar Utama (Add to Home screen)".
  • Di iPhone (Safari): Buka link web → klik ikon Bagikan (*Share* di bawah) → pilih "Add to Home Screen".
